The structure: where patterns.md fits 5 min

The skill loads in stages. Claude Code sees only the description until something matches. Then it loads SKILL.md, which decides which references to read. The change does not touch that mechanism: patterns.md is just another reference, with a special rule saying it is always read.

Who wins when two rules clash

patterns.md defines an explicit precedence order. The patterns are house rules: they outrank the skill's defaults, but yield to the user and to the project's design system.

How it is checked

Each eval case runs with and without the plugin, so the report shows what the skill adds, not just whether the model solves the task. The change adds three things to the suite:

PieceWhat it checks

The dynamics of an eval run 10 min

The patterns-read grader only makes sense in the with-plugin arm: without the skill, nobody knows patterns.md exists. That is why it carries arm: with-only. Without it, the no-plugin arm would always fail and the Δ would come out inflated.

Design decisions

What was chosen and what was rejected
DecisionRejected alternativeWhy
Patterns in a separate fileWriting them inside SKILL.mdSKILL.md stays close to the dogum/html-artifacts original, so pulling upstream changes does not conflict with the fork's own rules.
Always read, apply per «When»Reading it only for some categoriesThe patterns are cross-cutting: a sequence diagram or local context shows up in reports, explainers and reviews alike.
Explicit precedence in the fileLetting the model decideWithout a written order, a house pattern could override a project's design system.
Spanish triggers in the descriptionTrusting the model to translateThe description is the only thing visible before the skill loads. Whatever is not there does not fire it reliably.
A negative case in SpanishPositive cases onlyWidening the triggers raises the risk of turning a one-sentence answer into a page.

Risks and limits

  • Reading is not applying. patterns-read proves there was a Read, not that the rules were followed. Only the invoicing case has an llm grader that checks application.
  • Fixed cost per activation. Every page pays for reading patterns.md. Today it is about 90 lines; if it grows, it should be split into sections.
  • Description limit. CI cuts off at 1536 characters. Every new trigger eats into the margin.
  • Prefixed names. In Claude Code a plugin's skill shows up as plugin:folder. The skill-fired graders accept that format with a regex; the final fix landed in 1.0.1 along with the folder rename.
